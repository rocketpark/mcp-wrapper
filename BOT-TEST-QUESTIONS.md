## 🎯 Priority Test Scenarios

### Critical Path Tests (Must Work)
1. ✅ "Where is your California office?" → Returns San Diego & LA offices
2. ✅ "What services do you offer?" → Lists top services
3. ✅ "Tell me about fire protection" → Service description + link
4. ✅ "Who should I contact?" → Provides contact info/form
5. ✅ "What's new?" → Recent news/blog posts

### High-Value Conversions
1. 💰 "How do I get a quote?" → Lead capture
2. 💰 "I need help with [service]" → Expert connection
3. 💰 "Can you review my building?" → Consultation booking
4. 💰 "I have a compliance issue" → Urgent response pathway

### User Experience Tests
1. 🎯 Context maintenance across multiple questions
2. 🎯 Graceful handling of "I don't know" scenarios
3. 🎯 Helpful suggestions when no results found
4. 🎯 Natural language variations of same question

## 📝 Testing Checklist

### Before Demo
- [ ] Test all "Critical Path" questions
- [ ] Verify office location queries return complete info
- [ ] Check service queries link to correct pages

- [ ] Test follow-up questions maintain context

### During Demo
- [ ] Start with simple: "What services do you offer?"
- [ ] Show location query: "Where is your California office?"

### After Demo
- [ ] Collect questions asked during demo
- [ ] Note any failed queries
- [ ] Update bot instructions if needed
- [ ] Add new test cases based on feedback

## 🚀 Pro Tips for Demonstrating

### Best Questions to Start With
1. "What services do you offer?" - Shows breadth
2. "Where is your California office?" - Shows accuracy
3. "Tell me about fire protection services" - Shows depth
4. "Who are your experts?" - Shows people integration
5. "What's new at Jensen Hughes?" - Shows news integration

### Questions That Wow
- "Show me offices in California and what services they provide" (multi-part)
- "Find me a fire protection expert in San Diego" (smart filtering)
- Ask same question 3 different ways (natural language understanding)
- Update CMS content mid-demo, ask again (live data proof)

### Questions to Avoid in Demo
- ❌ Highly technical code questions (may not have content)
- ❌ Specific employee names (privacy concerns)
- ❌ Pricing questions (may be sensitive)
- ❌ Anything you haven't verified works

## 🎓 Training the Bot

### Update Bot Instructions When:
- Users frequently ask questions the bot can't answer
- New services are added to CMS
- New offices open
- Common follow-up patterns emerge
- Edge cases are discovered

### Improve Responses When:
- Bot provides too much information (be concise)
- Bot provides too little information (add depth)
- Bot doesn't understand variations (add examples)
- Bot suggests wrong next steps (fix instructions)
