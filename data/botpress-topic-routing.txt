## How to use this map

When a user asks "Who are your experts in [topic]?" or "Do you offer [topic] services?" and tool calls return zero/ambiguous results:

1. Look up the topic in the Topic → Service Routing Table above.
2. If matched: respond per prompt Rule 10 matched pattern with the mapped service name + URL.
3. If unmatched: fall back to the regional services landing page (Rule 10 fallback pattern).
4. For regional users (not NA), substitute the regional URL prefix per Regional Services Reference document — but NEVER for the dedicated topic pages above (those are NA-only slugs). For regional users, link the regional services landing instead.

## Topic-Specific Notes (content gaps + clarifications)

### Combustible Dust — DEDICATED PAGE EXISTS
JH has `/services/combustible-dust-safety` — a dedicated service page. Route Combustible Dust / DHA / Dust Hazard Analysis / Explosion Protection queries here directly. (Process Safety is the parent practice but the specific page is the right destination.)

### BESS / Battery Energy Storage / Lithium Ion
The dedicated service page is `/services/lithium-ion-risk-consulting` (Lithium-Ion Risk Consulting). This covers BESS facilities, lithium-ion battery hazards, UL 9540A testing partnership with the Large-Scale Fire Testing team, and emerging energy storage risks. Available in NA. For Pacific, route to `/pacific/services/energy-sustainability` (Pacific exception per Rule 4).

### LSFT — Large-Scale Fire Testing
Real prod URL: `/services/large-scale-fire-testing-lsft` (NOT `/services/fire-testing` which returns 404). JH operates multiple fire testing labs; the "in-house laboratories" page (`/services/in-house-laboratories-testing`) lists locations. If a user asks "where do you do LSFT?" or "what labs do you have?", link the in-house labs page. The new SMS lab in Utah may not yet be reflected on the prod site — pending Sarah Pichardo update.

### LNG / Cryogenics
JH does NOT have a dedicated LNG service page. Route to Process Safety (`/services/process-safety`) as the closest match.

### BIM / BIMfire
Always link the BIMfire insights article. NOT the Fire Engineering services page. The article explains JH's BIM integration approach.

### Digital Solutions
JH's Digital Solutions umbrella covers DataAdvisr, ProtectAdvisr, and cybersecurity/OT consulting. Real URL: `/services/digital` (NOT `/services/digital-services`).

### AHJ Representation + Plan Review
Dedicated page at `/services/ahj-representation-plan-review`. Use for any AHJ liaison / plan review / code official engagement queries.
