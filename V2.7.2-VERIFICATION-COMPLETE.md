## Issues Fixed

### 1. ✅ Hardcoded Jensen Hughes URLs Removed
**Original Problem**: Lines 520-521 in EntryTools.php contained hardcoded `jensenhughes.com` URLs

**Before**:
```php
'contactFormUrl' => "https://www.jensenhughes.com/contact/office-locations/form/{$slug}",
'officeDetailsUrl' => $office->url ?? "https://www.jensenhughes.com/{$office->uri}",
```

**After**:
```php
// Get site-specific settings from config
$config = Craft::$app->getConfig()->getConfigFromFile('mcpwrapper');
$siteSettings = $config['siteSettings'] ?? [];
$baseUrl = $siteSettings['baseUrl'] ?? Craft::$app->sites->primarySite->baseUrl;
$contactFormPath = $siteSettings['officeContactFormPath'] ?? '/contact/office-locations/form';

'contactFormUrl' => "{$baseUrl}{$contactFormPath}/{$slug}",
'officeDetailsUrl' => $office->url ?? "{$baseUrl}/{$office->uri}",
```

### 2. ✅ Analytics Dashboard Utility Fixed
**Original Problem**: Analytics routes registered but utility used redirect instead of inline render

**Before**:
```php
public static function contentHtml(): string
{
    Craft::$app->getResponse()->redirect('mcp-wrapper/analytics')->send();
    return '';
}
```

**After**:
```php
public static function contentHtml(): string
{
    $config = Craft::$app->getConfig()->getConfigFromFile('mcpwrapper');
    $schemas = array_keys($config['schemas'] ?? []);
    $selectedSchema = $schemas[0] ?? null;
    
    return Craft::$app->getView()->renderTemplate('mcp-wrapper/analytics/index', [
        'schemas' => $schemas,
        'selectedSchema' => $selectedSchema,
        'days' => 7,
    ]);
}
```

## Configuration Added

### New `siteSettings` Section

Added to `config/mcpwrapper.php.example`:
```php
'siteSettings' => [
    // Base URL for generating absolute URLs (optional)
    // Falls back to Craft's primary site URL if not specified
    'baseUrl' => getenv('PRIMARY_SITE_URL'),
    
    // Office contact form path template
    // Use {slug} as placeholder for office slug
    'officeContactFormPath' => '/contact/office-locations/form',
],
```

**Benefits**:
- Site-specific URLs configurable per-environment
- No hardcoded values in plugin code
- Configuration stays out of public repository
- Falls back to Craft's primary site URL
